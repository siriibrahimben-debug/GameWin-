# GameWin — prototype
Version de démonstration locale.
Fonctions : profil joueur, quiz, points, classement, récompenses et mini espace administrateur.
Les données sont stockées dans le navigateur (localStorage). Ce prototype ne gère pas d'argent réel, de paiements ou de jeu d'argent.

Pour lancer : ouvre index.html dans un navigateur.
Pour une vraie plateforme en ligne : ajouter serveur, base de données, authentification sécurisée, anti-triche, gestion des récompenses, modération et conformité juridique.
